## Isolir

- Alias: Suspended
- Arti: Status pemutusan sementara akses internet pelanggan akibat keterlambatan pembayaran atau kendala administrasi.
- Sumber: job_id=d8dde8b637f74ba9b1e1e10251526e6a

## Terminate

- Alias: Disconnect
- Arti: Status pemutusan permanen layanan berlangganan customer.

## Dismantled

- Alias: Tarik Aset
- Arti: Proses pengambilan kembali perangkat modem milik perusahaan dari lokasi pelanggan yang telah terminate.

## Fasum

- Alias: Fasilitas Umum
- Arti: Kategori pelanggan segmen non-komersial/sosial seperti rumah ibadah atau pos keamanan.
- Sumber: job_id=d8dde8b637f74ba9b1e1e10251526e6a

## Bun.js

- Alias: Bun
- Arti: Runtime JavaScript serba guna berkecepatan tinggi pengganti Node.js/Python yang menyertakan bundler, test runner, dan package manager bawaan.
- Sumber: job_id=132fd75afae34151bba9c98f92ac4220

## Whisper.cpp

- Alias: whisper-cpp
- Arti: Port C/C++ performa tinggi dari model Whisper ASR buatan OpenAI untuk inferensi lokal cepat tanpa dependensi Python berat.
- Sumber: job_id=132fd75afae34151bba9c98f92ac4220

## GGML

- Alias: ggml-format
- Arti: Format biner model machine learning teroptimasi untuk komputasi inferensi hemat memori pada CPU/GPU.
- Sumber: job_id=132fd75afae34151bba9c98f92ac4220

## large-v3-turbo

- Alias: v3-turbo
- Arti: Varian model Whisper fine-tuned OpenAI yang dioptimalkan untuk kecepatan transkripsi tinggi dengan akurasi setara model large.
- Sumber: job_id=132fd75afae34151bba9c98f92ac4220

## Stock Opname

- Alias: Stock of Num, Opname Stok
- Arti: Proses penghitungan fisik persediaan barang/modem di gudang atau lapangan untuk diverifikasi dengan pencatatan pembukuan di sistem ERP.
- Sumber: job_id=9c496b1f691b41c79bc291fb233f1dd3

## ODP

- Alias: Optical Distribution Point
- Arti: Kotak terminasi kabel distribusi fiber optik tempat penyambungan kabel drop wire menuju perangkat pelanggan.
- Sumber: job_id=9c496b1f691b41c79bc291fb233f1dd3

## Revisi Jalur

- Alias: Rerouting
- Arti: Proses penyesuaian rute bentangan kabel teknisi dari titik pelanggan ke ODP alternatif akibat kendala jarak atau kapasitas port.
- Sumber: job_id=9c496b1f691b41c79bc291fb233f1dd3

## Port ODP

- Alias: Port
- Arti: Titik konektor individual di dalam kotak ODP yang dialokasikan khusus untuk satu sambungan layanan pelanggan.
- Sumber: job_id=9c496b1f691b41c79bc291fb233f1dd3

## PSA

- Alias: Performance Service Agreement
- Arti: Perjanjian performa layanan kerja berisi indikator target kinerja sebagai dasar evaluasi kontrak personel.
