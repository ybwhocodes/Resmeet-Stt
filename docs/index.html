Resmeet-STT: Enterprise Meeting Notetaker

Solusi transkripsi audio rapat lokal dan generator Minutes of Meeting (MoM) otomatis berbasis Bun.js runtime, model whisper.cpp dengan akselerasi Apple Silicon Metal / CPU NEON, ekstraksi topik terarah Jev-ultrafast, dan visualisasi interaktif Markmap Mindmap.

Buka Web App (Port 5173) ↗ Mulai Tutorial Setup Dari Awal ↓

1. Pengenalan Sistem

Resmeet-STT dirancang khusus untuk memecahkan masalah transkripsi rapat bahasa Indonesia yang lambat, boros RAM, dan menghasilkan teks mentah yang berantakan. Sistem ini menggantikan stack Python tradisional yang berat dengan arsitektur modern berkinerja tinggi:

⚡ Bun.js + TypeScript

Backend concurrency tinggi dengan waktu startup instan, konsumsi memori rendah (<100MB), dan streaming progress WebSocket Socket.IO realtime.

🧠 Whisper.cpp Q5 Quantized

Engine C++ teroptimasi dengan bobot model kuantisasi large-v3-turbo-q5_0 (546 MB) dan Flash Attention untuk inferensi super cepat di Apple Silicon/CPU.

🎯 Jev-Guided Topics + RAG

Menentukan agenda, goal rapat, substansi argumen, keputusan mutlak, dan tindak lanjut (action items) yang terarah secara otomatis.

2. Fitur Unggulan

  • Pemilihan 3 Combo Pipeline: Opsi konfigurasi audio & model sebelum menjalankan proses sesuai kebutuhan akurasi atau kecepatan.
  • 3 Format Output Rapat: MoM Markdown standar (.md), Rangkuman visual interaktif (HTML/UI), dan Mindmap diskusi pohon topik (Markmap).
  • Pilihan Tipe Parafrase AI: Fleksibilitas memilih gaya "Poin-poin Penting" (ringkas & padat), "Detail & Deskriptif" (komprehensif), atau "Ringkasan Eksekutif".
  • Halaman Riwayat Khusus & Detail: Tabel riwayat multi-kolom yang dilengkapi pencarian, viewer detail lengkap, dan tombol hapus transkrip.
  • Pengaturan AI Terpusat: Konfigurasi endpoint URL, API-Key, model ID, uji koneksi langsung, dan preflight checklist sistem.

4. Tutorial Setup Lengkap: Dari Nol Sampai Berjalan

Ikuti langkah-langkah terstruktur berikut mulai dari cloning repository hingga aplikasi aktif di browser:

1 Clone Repository Proyek

Buka terminal dan clone repository Resmeet-STT ke direktori lokal Anda:

# Menggunakan SSH (Rekomendasi)
git clone git@github.com:ybwhocodes/Resmeet-Stt.git

# ATAU Menggunakan HTTPS
git clone https://github.com/ybwhocodes/Resmeet-Stt.git

# Masuk ke direktori
cd Resmeet-Stt

2 Unduh Bobot Model Whisper GGML

Buat direktori backend/models dan unduh bobot model Whisper GGML kuantisasi berkecepatan tinggi:

mkdir -p backend/models

# 1. Model Utama: Large-v3-Turbo Q5_0 (~546 MB) - Akurasi Tertinggi
curl -L -o backend/models/ggml-large-v3-turbo-q5_0.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin

# 2. Model Cepat: Base (~141 MB) - Kecepatan Super (<3 detik)
curl -L -o backend/models/ggml-base.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin

3 Siapkan Database MySQL

Aplikasi membutuhkan database MySQL bernama stt_db pada port 3307. Jalankan satu baris perintah Docker berikut:

docker run -d \
  --name mysql_db \
  -p 3307:3306 \
  -e MYSQL_ROOT_PASSWORD=password \
  -e MYSQL_DATABASE=stt_db \
  mysql:8.0

Tip: Backend Bun.js memiliki fitur auto-migration skema, sehingga seluruh tabel dan kolom (termasuk directed_topics dan ai_data) otomatis dibuat saat pertama kali server dinyalakan.

4 Salin & Atur Environment Backend

Salin file konfigurasi contoh menjadi file .env:

cp backend/.env.example backend/.env

Isi default pada backend/.env sudah terkonfigurasi untuk MySQL lokal port 3307. Anda dapat menyesuaikan endpoint AI LLM Anda jika menggunakan OpenAI, OpenRouter, atau Ollama:

5 Menjalankan Seluruh Stack Aplikasi

Pilih salah satu dari 3 metode eksekusi di bawah ini:

Metode A: 1-Click Startup Script (Paling Praktis)

Jalankan script start.sh untuk mengaktifkan MySQL, Backend Bun, dan Frontend Vite secara bersamaan:

# Berikan izin eksekusi jika pertama kali
chmod +x start.sh

# Jalankan seluruh stack
./start.sh

Metode B: Full Docker Compose

Jalankan seluruh sistem (MySQL, Backend Bun, dan Frontend Nginx) terisolasi di dalam container Docker:

# Jalankan container di background
docker compose up -d

# Pantau log
docker compose logs -f

# Menghentikan layanan
docker compose down

Metode C: Menjalankan Manual (Step-by-Step)

Jika ingin menjalankan backend dan frontend secara manual di terminal terpisah:

Terminal 1 — Backend Bun: 
cd backend
bun install
pip install numpy scipy soundfile noisereduce onnxruntime torch
bun run src/index.ts
# Aktif di http://localhost:8081
Terminal 2 — Frontend React + Vite: 
cd frontend
npm install
npm run dev
# Aktif di http://localhost:5173

7. Pilihan Tipe Parafrase AI

Resmeet-STT menyediakan 3 opsi gaya parafrase AI yang dapat dipilih melalui menu Pengaturan maupun toolbar hasil rapat:

Poin-poin Penting

Deskripsi singkat, to the point, padat, dan cepat dipindai pembaca (minimal 2 paragraf per poin) dengan penjelasan konteks yang terarah.

Detail & Deskriptif

Penjelasan komprehensif latar belakang, argumen peserta rapat, dan rincian teknis aksi (minimal 4 paragraf panjang) dilengkapi insight & analisis deskriptif mendalam agar pembaca yang tidak ikut meeting paham seutuhnya.

Ringkasan Eksekutif

Format strategis tingkat manajemen pengambil keputusan (minimal 2 paragraf per poin) dilengkapi konteks dan analisis pro-kontra setiap keputusan.

9. Troubleshooting & FAQ

Q: whisper-cli error exit code 10 saat menggunakan Combo 3?

Masalah ini terjadi jika flag --vad diberikan pada whisper-cli tanpa file model VAD terpisah. Pada versi terbaru, segmentasi VAD Silero-VAD dilakukan langsung di fase pra-proses Python dengan ONNX runtime, sehingga whisper-cli memproses audio bersih tanpa error.

Q: Mengapa whisper.cpp jauh lebih hemat RAM dibanding Python faster-whisper?
Whisper.cpp dikompilasi langsung ke native C++ dengan pustaka GGML yang dioptimasi khusus untuk arsitektur CPU dan Apple Silicon Metal. Kuantisasi bobot ke format Q5_0 mereduksi ukuran memori dari 1.5GB menjadi hanya ~546MB tanpa kehilangan akurasi kata.
