02 / MODEL & OPTIMASI PERFORMA

Akurasi Whisper large-v3-turbo dengan Pipeline Tanpa Penurunan Kualitas

Resmeet mempertahankan bobot model large-v3-turbo secara penuh tanpa menurunkan ukuran model ke base atau small, sambil mempercepat eksekusi melalui pemangkasan keheningan dan paralelisasi.

Komponen Model File / Direktori Peran di Pipeline Target Eksekusi
Whisper large-v3-turbo (GGML Q5_0) backend/models/ggml-large-v3-turbo-q5_0.bin Mesin transkripsi utama berkecepatan tinggi dengan akurasi multibahasa dan Indonesia GPU Vulkan (/dev/dri/renderD128) sebagai default atau CPU fallback
Silero VAD v6.2.0 backend/models/ggml-silero-v6.2.0.bin Mendeteksi segmen ucapan vs keheningan sebelum decoder berjalan Aktif di dalam whisper-server dan faster-whisper
Faster-Whisper large-v3-turbo (INT8) backend/models/faster-whisper-large-v3-turbo/ Mesin cadangan CTranslate2 INT8 ketika perangkat GPU Vulkan tidak tersedia CPU Multi-thread (CPU_THREADS=6)

Prinsip Optimasi Tanpa Kompromi Kualitas

Alih-alih mengganti ke model yang lebih kecil, percepatan dilakukan pada bagian yang tidak membawa informasi ucapan: membuang keheningan panjang, menghilangkan pengulangan decoding saat audio sunyi, membersihkan noise rendah/tinggi sebelum masuk encoder, dan memproses dua potongan audio secara bersamaan.

Saat GPU render node (/dev/dri/renderD128) terdeteksi melalui driver Vulkan (libggml-vulkan.so), sistem otomatis menetapkan GPU sebagai perangkat default dengan opsi CPU tetap siap di Pengaturan.

1. Pemangkasan Hening Agresif (Silero VAD)

-vt 0.50 · -vsd 100 · -vspd 250

Melewati segmen diam sehingga Whisper hanya memproses ucapan aktif sambil tetap mempertahankan padding 50 ms agar ujung kata tidak terpotong.

2. Non-Fallback Decoding

-nf · temperature=0.0

Menghentikan loop re-decoding berulang saat menemui jeda nafas atau batuk sehingga waktu proses tidak membengkak.

3. Chunking 45 Detik Berbasis Jeda Napas

STT_CHUNK_SECONDS=45

Mencari titik sunyi terdekat (silencedetect=noise=-35dB:d=0.3) di sekitar detik ke-45 dengan overlap aman +-0.5 detik.

4. Pembersih Frekuensi Audio FFmpeg

highpass=80 · lowpass=7500 · afftdn

Menghilangkan gemuruh AC, dengung mic, dan desis statis sebelum sinyal masuk ke model Whisper.

5. Paralelisasi Pool Inferensi

STT_CONCURRENCY=2 · EnginePool

Ekstraksi chunk audio dan inferensi berjalan paralel di pipeline.rs dengan checkpoint atomik ke PostgreSQL.

03 / FITUR UTAMA APLIKASI

Alur Lengkap dari Rekaman Suara hingga Dokumen Resmi

Seluruh modul dirancang agar hasil transkrip mentah, dokumen yang dirapikan AI, serta riwayat pekerjaan tetap aman dan dapat ditinjau ulang kapan saja.

Alur Audio & Keandalan Sistem

Fondasi pemrosesan file besar dan kontrol kesiapan sebelum job dimulai.

  • Preflight Gate & Diagnosa Otomatis Mengunci tombol transkripsi jika worker, PostgreSQL, FFmpeg, model, atau folder upload belum siap, lengkap dengan penyebab dan langkah perbaikan.
  • Rekam Mikrofon & Multi-Format Upload Mendukung unggahan MP3, WAV, M4A, OGG, FLAC, WEBM, MP4, MPEG, MPG, MPE, dan MPGA dengan ekstraksi suara otomatis dari video.
  • Checkpoint per Chunk & Live Preview Hasil tiap potongan 45 detik langsung disimpan ke transcription_chunks sehingga progres dapat dipantau real-time dan dilanjutkan otomatis jika restart.
  • Sakelar GPU Vulkan / CPU Per Akun Deteksi otomatis GPU render node sebagai pilihan utama dengan opsi fallback CPU INT8 pada menu Pengaturan.

Notulen, Dokumen & Kolaborasi

Alat penyuntingan dan penyajian hasil rapat untuk tim dan pimpinan.

  • Sakelar Model AI ON / OFF Opsional Transkrip asli Whisper selalu tersimpan. Saat AI diaktifkan, worker terpisah merapikan ejaan tanpa mengubah makna serta menyusun MoM terstruktur.
  • Editor DOCX Native Standar A4 Menyunting dokumen MoM langsung di browser melalui @docx-editor.dev, mendukung unduhan file .docx, cetak PDF, dan judul MoM kustom.
  • Peta Pikiran Interaktif (Markmap) Menyajikan struktur topik dan keputusan rapat sebagai diagram mindmap interaktif yang dapat dieksplorasi.
  • Tautan Publik, Multi-User & Enkripsi AES-256-GCM Bagikan MoM secara read-only, kelola akun Superadmin/User dengan autentikasi PBKDF2, serta amankan API Key Gateway AI di database.

Demi keamanan kredensial dan ukuran repositori, beberapa file penting sengaja dikecualikan di .gitignore. Siapkan berkas berikut sebelum menjalankan aplikasi.

backend/.env Konfigurasi runtime lokal untuk start-non-docker.sh Salin dari template: cp backend/.env.example backend/.env (pastikan DB_HOST=127.0.0.1).

LANGKAH INSTALASI

Pilih Mode Eksekusi

LANGKAH 1

Clone Repositori & Siapkan File Environment (.env)

Pastikan Docker Engine, Docker Compose v2, dan PostgreSQL sudah tersedia. Salin .env.example menjadi .env.

git clone <url-repositori-resmeet-stt> Resmeet-Stt
cd Resmeet-Stt
cp .env.example .env
LANGKAH 2

Siapkan Database PostgreSQL di Port 5433

Jika belum memiliki instance PostgreSQL berjalan, buat container PostgreSQL dengan database stt_db.

docker run -d --name postgres_db \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=password \
  -e POSTGRES_DB=stt_db \
  -p 5433:5432 \
  postgres:16
LANGKAH 3

Unduh Model Whisper large-v3-turbo & Silero VAD

Model tidak disimpan di Git karena ukurannya besar. Unduh kedua file berikut ke backend/models/.

mkdir -p backend/models
curl -L -o backend/models/ggml-large-v3-turbo-q5_0.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin
curl -L -o backend/models/ggml-silero-v6.2.0.bin \
  https://huggingface.co/ggml-org/whisper-vad/resolve/main/ggml-silero-v6.2.0.bin
LANGKAH 4

Jalankan dengan start-docker.sh

Script akan mengaudit .env, Docker daemon, PostgreSQL, file model, GPU Vulkan /dev/dri/renderD128, lalu memverifikasi /api/preflight secara otomatis.

chmod +x start-docker.sh
./start-docker.sh --build
LANGKAH 5

Buka Aplikasi & Buat Akun Superadmin

Akses http://localhost:5173. Pada database kosong, isi pop-up setup awal dengan password minimal 12 karakter, lalu cek badge status hijau Ready di kiri atas.

curl -s http://localhost:8200/api/preflight
# Untuk menghentikan seluruh container:
./start-docker.sh --down
LANGKAH 1

Pasang Dependensi Sistem (Rust, Node.js, FFmpeg, Compiler)

Mode native mengompilasi backend Rust langsung di host dan menjalankan Vite frontend tanpa container aplikasi.

sudo apt update
sudo apt install -y build-essential pkg-config libssl-dev ffmpeg curl git python3 python3-venv
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
# Pastikan Node.js v20+ / v22 LTS dan PostgreSQL (port 5432 atau 5433) aktif
LANGKAH 2

Siapkan Mesin Inferensi Whisper (Pilih Vulkan GPU atau CPU INT8)

Anda dapat mengompilasi whisper-server (mendukung GPU Vulkan/CPU) atau menggunakan venv Python faster-whisper.

# Opsi A: Kompilasi whisper-server (tambahkan -DGGML_VULKAN=1 jika ada GPU Vulkan)
git clone https://github.com/ggml-org/whisper.cpp /tmp/whisper.cpp
cmake -S /tmp/whisper.cpp -B /tmp/whisper.cpp/build -DGGML_VULKAN=1
cmake --build /tmp/whisper.cpp/build -j"$(nproc)" --target whisper-server
sudo cp /tmp/whisper.cpp/build/bin/whisper-server /usr/local/bin/

# Opsi B: Faster-Whisper CPU INT8 via virtualenv
python3 -m venv backend/.venv
backend/.venv/bin/pip install faster-whisper==1.2.1 av==18.1.0
LANGKAH 3

Siapkan backend/.env & Unduh Model ke backend/models/

Pastikan DB_HOST=127.0.0.1 di backend/.env (bukan host.docker.internal).

cp backend/.env.example backend/.env
mkdir -p backend/models backend/uploads backend/transcripts_md
curl -L -o backend/models/ggml-large-v3-turbo-q5_0.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin
curl -L -o backend/models/ggml-silero-v6.2.0.bin \
  https://huggingface.co/ggml-org/whisper-vad/resolve/main/ggml-silero-v6.2.0.bin
LANGKAH 4

Jalankan Aplikasi dengan start-non-docker.sh

Script memeriksa Rust, Node, FFmpeg, Whisper, model, koneksi PostgreSQL, dan port 8200/5173 sebelum memulai 4 proses lokal (API, Worker, AI-Worker, Vite).

DIAGNOSA & TROUBLESHOOTING

Penanganan Status "Transkripsi Belum Dapat Dimulai"

Jika sistem menampilkan komponen belum siap pada UI atau saat menjalankan script startup, periksa penyebab spesifik berikut.

Worker Transkripsi berstatus Belum Siap (transcriptionWorker: false)
Worker belum mengirim heartbeat aktif ke tabel worker_heartbeats atau container worker mati. Jalankan docker compose up -d worker atau periksa log via docker logs resmeet_worker --tail 40.
PostgreSQL Database gagal terhubung (database: false)
Pastikan container postgres_db berjalan pada port 5433 dan database stt_db tersedia. Untuk mode Docker gunakan DB_HOST=host.docker.internal di .env; untuk mode non-Docker gunakan DB_HOST=127.0.0.1 di backend/.env.
Model Whisper GGML belum terdeteksi (whisperModel: false)
Pastikan file bobot model sesuai WHISPER_MODEL (default ggml-large-v3-turbo-q5_0.bin) tersedia dan tidak kosong di folder backend/models/.
Port 8200 atau 5173 bentrok saat menjalankan start-non-docker.sh
Container Docker Resmeet kemungkinan masih berjalan dan mengikat port tersebut. Hentikan mode Docker terlebih dahulu dengan ./start-docker.sh --down sebelum menjalankan mode lokal.
