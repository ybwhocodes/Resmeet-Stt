# Frontend React Resmeet STT

Frontend menggunakan React dan Vite. Jalankan `npm install`, lalu `npm run dev` untuk pengembangan atau `npm run build` untuk menghasilkan aset produksi.

Backend Rust tersedia di `http://localhost:8200`. Jalankan seluruh aplikasi dengan `npm run docker:up` dari direktori utama proyek. Halaman Preflight membaca `GET /api/preflight` dan menampilkan status komponen utama.
