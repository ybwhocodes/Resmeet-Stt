Resmeet-STT: Enterprise Meeting Notetaker

Solusi transkripsi audio rapat lokal dan generator Minutes of Meeting (MoM) otomatis berbasis Bun.js runtime (Port default 8200), model whisper.cpp dengan akselerasi Apple Silicon Metal / CPU NEON, dukungan multi-database SQLite (Default Mandiri), MySQL, & PostgreSQL dengan tombol migrasi in-app, ekstraksi topik terarah Jev-ultrafast, serta paket aplikasi Desktop .DMG & .EXE siap pakai.

📥 Download Desktop (.DMG / .EXE) ↓ Buka Web App (Port 5173) ↗ Tutorial Setup Web Server ↓
✨ Langsung Pakai Tanpa Perlu Git Clone

Unduh Aplikasi Desktop Resmeet-STT

Tersedia untuk macOS dan Windows. Cukup unduh installer, pasang, dan langsung jalankan secara mandiri dengan database SQLite bawaan tanpa setup terminal!

🍏 Unduh .DMG (macOS) 🪟 Unduh .EXE (Windows)

💻 Mode Program Lokal (Desktop Standalone)

Tanpa konfigurasi server. Menggunakan penyimpanan database SQLite bawaan (resmeet.sqlite) yang otomatis dibuat saat aplikasi dibuka. Cocok untuk laptop notulis, eksekutif, atau meeting offline.

  • Tidak memerlukan server MySQL atau Docker sama sekali.
  • Database lokal instan tanpa perlu tombol migrasi manual.
  • Semua berkas notulen, mindmap, dan rekaman tersimpan lokal.

🌐 Mode Web Server (Enterprise / Tim)

Untuk penggunaan bersama dalam jaringan kantor / VPS. Backend aktif pada Port default 8200, mendukung database SQLite, MySQL, atau PostgreSQL terpusat dengan tombol migrasi in-app.

  • Backend default port: http://localhost:8200
  • Frontend Vite dev server: http://localhost:5173
  • Dapat diakses oleh seluruh rekan tim melalui web browser.

1. Pengenalan Sistem

Resmeet-STT dirancang khusus untuk memecahkan masalah transkripsi rapat bahasa Indonesia yang lambat, boros RAM, dan menghasilkan teks mentah yang berantakan. Sistem ini menggantikan stack Python tradisional yang berat dengan arsitektur modern berkinerja tinggi:

⚡ Bun.js + TypeScript

Backend concurrency tinggi dengan waktu startup instan, konsumsi memori rendah (<100MB), dan streaming progress WebSocket Socket.IO realtime.

🧠 Whisper.cpp Q5 Quantized

Engine C++ teroptimasi dengan bobot model kuantisasi large-v3-turbo-q5_0 (546 MB) dan Flash Attention untuk inferensi super cepat di Apple Silicon/CPU.

🎯 Jev-Guided Topics + RAG

Menentukan agenda, goal rapat, substansi argumen, keputusan mutlak, dan tindak lanjut (action items) yang terarah secara otomatis.

2. Fitur Unggulan

  • Pemilihan 3 Combo Pipeline: Opsi konfigurasi audio & model sebelum menjalankan proses sesuai kebutuhan akurasi atau kecepatan.
  • 3 Format Output Rapat: MoM Markdown standar (.md), Rangkuman visual interaktif (HTML/UI), dan Mindmap diskusi pohon topik (Markmap).
  • Pilihan Tipe Parafrase AI: Fleksibilitas memilih gaya "Poin-poin Penting" (ringkas & padat), "Detail & Deskriptif" (komprehensif), atau "Ringkasan Eksekutif".
  • Halaman Riwayat Khusus & Detail: Tabel riwayat multi-kolom yang dilengkapi pencarian, viewer detail lengkap, dan tombol hapus transkrip.
  • Pengaturan AI Terpusat: Konfigurasi endpoint URL, API-Key, model ID, uji koneksi langsung, dan preflight checklist sistem.

4. Tutorial Setup Lengkap: Dari Nol Sampai Berjalan

Ikuti langkah-langkah terstruktur berikut mulai dari cloning repository hingga aplikasi aktif di browser:

1 Clone Repository Proyek

Buka terminal dan clone repository Resmeet-STT ke direktori lokal Anda:

# Menggunakan SSH (Rekomendasi)
git clone git@github.com:ybwhocodes/Resmeet-Stt.git

# ATAU Menggunakan HTTPS
git clone https://github.com/ybwhocodes/Resmeet-Stt.git

# Masuk ke direktori
cd Resmeet-Stt

2 Unduh Bobot Model Whisper GGML

Buat direktori backend/models dan unduh bobot model Whisper GGML kuantisasi berkecepatan tinggi:

mkdir -p backend/models

# 1. Model Utama: Large-v3-Turbo Q5_0 (~546 MB) - Akurasi Tertinggi
curl -L -o backend/models/ggml-large-v3-turbo-q5_0.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin

# 2. Model Cepat: Base (~141 MB) - Kecepatan Super (<3 detik)
curl -L -o backend/models/ggml-base.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin

3 Siapkan Database MySQL

Aplikasi membutuhkan database MySQL bernama stt_db pada port 3307. Jalankan satu baris perintah Docker berikut:

docker run -d \
  --name mysql_db \
  -p 3307:3306 \
  -e MYSQL_ROOT_PASSWORD=password \
  -e MYSQL_DATABASE=stt_db \
  mysql:8.0

Tip: Backend Bun.js memiliki fitur auto-migration skema, sehingga seluruh tabel dan kolom (termasuk directed_topics dan ai_data) otomatis dibuat saat pertama kali server dinyalakan.

4 Salin & Atur Environment Backend

5 Menjalankan Seluruh Stack Aplikasi

Pilih salah satu dari 3 metode eksekusi di bawah ini:

Metode A: 1-Click Startup Script (Paling Praktis)

Jalankan script start.sh untuk mengaktifkan MySQL, Backend Bun, dan Frontend Vite secara bersamaan:

# Berikan izin eksekusi jika pertama kali
chmod +x start.sh

# Jalankan seluruh stack
./start.sh

Metode B: Full Docker Compose

Jalankan seluruh sistem (MySQL, Backend Bun, dan Frontend Nginx) terisolasi di dalam container Docker:

# Jalankan container di background
docker compose up -d

# Pantau log
docker compose logs -f

# Menghentikan layanan
docker compose down

Metode C: Menjalankan Manual (Step-by-Step)

Jika ingin menjalankan backend dan frontend secara manual di terminal terpisah:

Terminal 1 — Backend Bun: 
cd backend
bun install
pip install numpy scipy soundfile noisereduce onnxruntime torch
bun run src/index.ts
# Backend aktif pada port default http://localhost:8200
Terminal 2 — Frontend React + Vite: 
cd frontend
npm install
npm run dev
# Frontend aktif di http://localhost:5173

6 Akses Antarmuka Web

Buka browser Anda di **http://localhost:5173**:

  1. Klik menu Pengaturan: Periksa checklist Preflight Status untuk memastikan modul uploads, knowledge, ffmpeg, format_mom, whisper_model, database semua centang hijau.
  2. Periksa bagian Penyimpanan Database: default menggunakan SQLite lokal mandiri tanpa setup. Jika menggunakan MySQL atau Postgres, masukkan data koneksi dan klik tombol Migrate Database.
  3. Klik tombol Uji Koneksi AI untuk memastikan integrasi LLM terhubung.
  4. Kembali ke menu Transkripsi: Drag & drop file audio/video rapat Anda (.mp4, .mpeg, .m4a, .mp3, .wav, dll.), pilih Combo 1, lalu klik Mulai Transkripsi & Analisis!

Penyimpanan Multi-Database & Tombol Migrasi

Resmeet-STT mendukung 3 mesin database yang dapat diganti secara dinamis langsung melalui menu Pengaturan di dalam aplikasi web maupun desktop:

1. SQLite (Default Mandiri)

Zero-Configuration: Default pertama kali aplikasi dijalankan jika MySQL/Postgres belum ada. File backend/resmeet.sqlite dibuat secara otomatis. Tabel transcripts langsung siap dipakai tanpa memerlukan server terpisah ataupun tombol migrasi manual.

2. MySQL Server

Cocok untuk server kantor. Masukkan Host (127.0.0.1), Port (3307/3306), Database (stt_db), User, dan Password. Dilengkapi tombol Uji Koneksi dan tombol Migrate Database.

3. PostgreSQL Server

Dukungan native database enterprise PostgreSQL (Port default 5432). Mendukung skema tabel relasional dan field JSON native untuk metadata topik dan audio rapat.

Tombol "Set Default" & Logika Migrasi Database

Setiap driver database dilengkapi fitur pengaturan default dan migrasi yang intuitif:

  • Tombol "Set Default Database" / Jadikan Default: Tersedia untuk SQLite, MySQL, maupun PostgreSQL. Mengklik tombol ini akan menyimpan driver yang dipilih ke file settings.json dan menjadikannya default permanen saat aplikasi dimulai kembali.
  • Indikator Badge "Default Aktif": Secara otomatis menampilkan status driver mana yang sedang aktif sebagai default sistem di bagian atas panel dan kartu driver.
  • Jika memilih SQLite: Tombol migrasi tidak diperlukan karena SQLite sudah otomatis terbuat dan termigrasi secara otomatis (zero-setup out-of-the-box). Anda cukup menekan tombol "Set SQLite Sebagai Default".
  • Jika memilih MySQL atau PostgreSQL: Tombol "Migrate Database" akan otomatis muncul. Saat diklik, backend membuat database (jika belum ada) dan mengeksekusi migrasi skema tabel transcripts beserta seluruh kolom JSON secara instan.
  • Tombol Uji Koneksi: Memverifikasi konektivitas jaringan, menghitung latensi server (ms), dan memastikan autentikasi berhasil sebelum migrasi dijalankan.

Cara Membuat (Build) File .DMG & .EXE Sendiri

Jika Anda seorang developer yang ingin mengompilasi file installer .dmg (macOS) atau .exe (Windows) sendiri dari source code:

Opsi 1: Menggunakan Script Otomatis (build-desktop.sh)

# Berikan izin eksekusi
chmod +x scripts/build-desktop.sh

# Jalankan script packaging lengkap
./scripts/build-desktop.sh

# Hasil build .dmg, .exe, dan binary akan tersimpan di folder release/
ls -lh release/

Opsi 2: Mengompilasi Binary Standalone dengan Bun Compile

# Kompilasi executable standalone macOS (Apple Silicon & Intel)
bun build --compile --minify backend/src/index.ts --outfile release/resmeet-mac

# Kompilasi executable standalone Windows (.exe)
bun build --compile --minify --target=bun-windows-x64 backend/src/index.ts --outfile release/resmeet-win.exe

7. Pilihan Tipe Parafrase AI

Resmeet-STT menyediakan 3 opsi gaya parafrase AI yang dapat dipilih melalui menu Pengaturan maupun toolbar hasil rapat:

Poin-poin Penting

Deskripsi singkat, to the point, padat, dan cepat dipindai pembaca (minimal 2 paragraf per poin) dengan penjelasan konteks yang terarah.

Detail & Deskriptif

Penjelasan komprehensif latar belakang, argumen peserta rapat, dan rincian teknis aksi (minimal 4 paragraf panjang) dilengkapi insight & analisis deskriptif mendalam agar pembaca yang tidak ikut meeting paham seutuhnya.

Ringkasan Eksekutif

Format strategis tingkat manajemen pengambil keputusan (minimal 2 paragraf per poin) dilengkapi konteks dan analisis pro-kontra setiap keputusan.

9. Troubleshooting & FAQ

Q: whisper-cli error exit code 10 saat menggunakan Combo 3?

Masalah ini terjadi jika flag --vad diberikan pada whisper-cli tanpa file model VAD terpisah. Pada versi terbaru, segmentasi VAD Silero-VAD dilakukan langsung di fase pra-proses Python dengan ONNX runtime, sehingga whisper-cli memproses audio bersih tanpa error.

Q: Mengapa whisper.cpp jauh lebih hemat RAM dibanding Python faster-whisper?
Whisper.cpp dikompilasi langsung ke native C++ dengan pustaka GGML yang dioptimasi khusus untuk arsitektur CPU dan Apple Silicon Metal. Kuantisasi bobot ke format Q5_0 mereduksi ukuran memori dari 1.5GB menjadi hanya ~546MB tanpa kehilangan akurasi kata.
